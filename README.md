# EPS-TOPIK Vocabulary Quiz

520-question EPS-TOPIK vocabulary quiz — "다음 설명에 알맞은 어휘를 고르십시오" (choose the vocabulary word that matches the description).

- **Live site:** https://sudip-pandey.github.io/eps-vocabs-/ (enable GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`)
- **Full quiz:** `full-quiz.html` — all 520 questions in one file
- **Sets:** `set-01` … `set-11` — 10 sets of 50 + 1 set of 20, each with its own progress (auto-saved), Submit + score + Nepali explanations

Answers are AI-generated — the book has no printed answer key. Check the answers with a teacher. Questions are renumbered 1–520 in order (the book's own numbering had gaps and duplicates).
